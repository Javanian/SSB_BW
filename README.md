# SSB Browser Workflow Prototypes

Standalone HTML prototypes for NFC-ID reading and operational forms, including driving-license and workforce workflows.

The pages are independent source files rather than a packaged application. They may require external services or configured endpoints; no complete local backend or automated test suite is included.

Review each page's endpoints and permissions before running it against a live service. Employee/ID mappings are excluded from this public repository. Runtime behavior and deployment were not verified during the repository cleanup.
